<H1>F1 telemetry and laptime viewing tool</H1>

This tool can visualise f1 telemetry from any session, in any lap, in various different ways, and can save most of the visualisations to the working directory

List of abilities:

<h3> View all laps set by a driver over one session: (Cannot be saved) </h3> 
    ⏺Puts all the laps set by a driver over the course of a session <br>
    ⏺ States the fastest lap made by that driver <br>
    ⏺ Includes total lap time, and individual sector times, as well as tyre compound and life <br>

<h3> Compare lap times over a session on a graph: </h3>
    ⏺ Up to 2 drivers <br>
    ⏺ Plots all of the set lap times over a session onto a graph.  <br>
    
<h3> View Throttle/Brake inputs over a lap: </h3>
    ⏺ Can be viewed on an animated bar chart (Throttle/Brake inputs, as well as speed are visualised on a moving bar chart) <br>
    ⏺ Can be viewed on a graph (Throttle/Brake inputs, as well as speed are visualised on a graph.) <br>

<h3> Compare/View a drivers lap in a session: </h3>
    ⏺Up to 2 drivers <br>
    ⏺ Can be viewed on an animated track map (Drivers, represented as moving points, are visuallised on a track map)  <br>
    ⏺Can be viewed in a graph (Drivers' speed(y) and distance(x) are plotted on a graph) <br>

(examples in 'Examples' folder)

This tool uses FastF1 library for all of its telemetry data and laptimes

(Note: linux users may have to download tkinter aswell if not installed already.)
